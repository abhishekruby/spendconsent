# Impact evidence (verified 22 Oct 2026)

Published surveys, read at the primary or named source. They describe consumer
attitudes in general, not our users; they do not prove demand for SpendConsent.

| Finding | Source |
| --- | --- |
| 60% would stop using an AI shopping agent after one mistake; 70% say purchases made without asking would affect their willingness to use one; only 19% trust AI to make everyday purchases even by rules they set. ACI's conclusion: prioritise "explicit approvals, hard spending limits, protected payment details and clear accountability". | [ACI Worldwide / YouGov](https://investor.aciworldwide.com/node/26576), 2,080 UK adults, 19–22 Jun 2026 |
| Approval before checkout is the single most requested safeguard globally. 42% of US millennials would give an agent up to $250 if a 7-day return is guaranteed, vs 34% without. | [RTB House via Chain Store Age](https://chainstoreage.com/rtb-house-consumer-trust-agentic-ai-grows), 1,840 respondents in US, UK, FR, JP, Jun–Jul 2026 |
| A major retailer's terms treat agent purchases as "transactions authorized by you", so a wrong agent purchase is the customer's cost. | [eMarketer on Target's terms](https://www.emarketer.com/content/target-limits-liability-ai-shopping-assistants-gain-traction) (secondary; check the terms page before quoting) |
| Routine ordering takes 4–7 hours a week across an organization (Walmart Business executive's estimate, not a survey). | [PYMNTS](https://www.pymnts.com/smbs/2026/walmart-business-targets-the-invisible-work-slowing-small-business-down/), Jun 2026 |

## How SpendConsent answers each safeguard

| Safeguard people ask for | SpendConsent |
| --- | --- |
| Explicit approval before checkout | Exact-cart review; approval binds merchant, item, quantity, charges and total; any change voids it |
| Hard spending limits | Spending rule (category, per-order cap, monthly count), checked by code, not the model |
| Protected payment details | The agent never sees payment data; PayPal holds the saved account |
| Accountability when it goes wrong | One-tap undo: a full PayPal refund, verified against the capture |
| Agent mistakes | Exact size/quantity/budget checks; 160/160 on blind AI tests; the agent cannot approve or pay |
